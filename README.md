# Project Name

Task planner

## The Problem

Many students procrastinate a lot in their assignments/exams, and they want to be more
productive.

## How It Works

It takes the information like deadlines/needed time/importance score for an assignment/exam, it ranks the order
of the tasks based on these 3 pieces of information.
